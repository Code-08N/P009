# Design Deck

**Design Deck** is an experimental educational tool for design ideation.

It was developed to help students move away from collecting random references or copying visual forms, and instead learn how to **extract, combine and transform ideas** from different sources.

The system uses a set of image-based cards divided into three categories:

- **MODEL** — defines a person, attitude, style or cultural context for whom the project could be designed.
- **STRUCTURE** — provides an existing product typology or structural starting point. It is not intended as a fixed constraint, but as something that can be transformed.
- **IMG / PRINCIPLE** — provides an image from which the student must identify a transferable principle: a structural logic, behaviour, relationship, transformation, construction method or formal rule.

Each student receives:

**2 MODEL + 2 STRUCTURE + 2 IMG / PRINCIPLE**

Cards of the same category can be exchanged between students, but each participant must always retain the same number of cards for each category.

The objective is not to directly combine the visual appearance of the cards.

Instead, the student is asked to understand:

**What can I extract from this image?**
**What principle can be transferred?**
**How can it interact with a different structure, person or context?**

The cards act as **starting conditions for a design process**, introducing constraints while leaving enough freedom for interpretation.

---

## Why

Design students often struggle not because they lack references, but because they do not know **how to use references**.

Images are frequently collected because they are aesthetically appealing, without understanding what specifically makes them interesting or how that information could be transferred into a new project.

Design Deck shifts the focus from:

**IMAGE → FORM → COPY**

towards:

**IMAGE → ANALYSIS → PRINCIPLE → TRANSFORMATION**

The aim is to train the ability to recognize transferable ideas rather than reproduce existing aesthetics.

---

## Process

A possible workflow is:

**MODEL**
Who is this for?
How do they dress?
What environment or cultural context do they belong to?

↓

**STRUCTURE**
What existing typology can be used as a starting point?

↓

**PRINCIPLE**
What behaviour, logic or relationship can be extracted from the reference image?

↓

**EXPERIMENTATION**
How can these elements interact and generate alternatives?

↓

**DESIGN**

The resulting project does not need to visibly resemble any of the original cards.

The cards are a trigger, not a destination.

---

## Status

Design Deck is currently an **experimental educational system**.

The structure, card selection and methodology are intended to evolve through teaching, testing and iteration.
